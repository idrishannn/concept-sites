## Portfolio text (Upwork, max 600 characters)
Concept site for Sumakara, a fictional Anatolian charcoal grill & meze house, built around what diners look for: a real HTML menu with dietary filters (vegan, gluten-free, spicy), today's hours and an open-now status, a 3-step reservation widget with a live receipt-style summary, and a private dining inquiry with set menus. Bold custom identity with a stretching variable-font wordmark, hand-made SVG illustrations, responsive and accessible (WCAG AA). Built with Astro and Tailwind CSS.
Live demo: https://concept-sites-drab.vercel.app/restaurant/
